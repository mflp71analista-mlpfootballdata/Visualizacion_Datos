# 🎨 Football Data Visualization Gallery (Python)

Este repositorio recopila diversos módulos y scripts en **Python** enfocados en la representación gráfica y visualización táctica avanzada de datos de fútbol. El objetivo es transformar métricas complejas en informes visuales intuitivos para analistas, cuerpos técnicos y direcciones deportivas.

---

## 🛠️ Stack Tecnológico

* **Lenguaje:** Python
* **Librerías de Visualización Táctica:** Mplsoccer, Matplotlib, Seaborn
* **Procesamiento de Datos:** Pandas, NumPy
* **Fuentes de Datos Representadas:** Wyscout, StatsBomb, FBref

---

## 📊 Tipologías de Visualización Incluidas

### 1. Análisis de Eventos sobre el Terreno de Juego
* **Mapas de Calor (Heatmaps) & Zonas de Actividad:** Representación de áreas de influencia y ocupación de espacios de jugadores y equipos.
* **Redes de Pases (Passing Networks):** Diagramas de interacción y volumen de circulación de balón entre posiciones medias.
* **Mapas de Tiros (Shot Maps):** Gráficos de intentos de remate ponderados por calidad de ocasión ($xG$).

### 2. Comparativa & Perfiles de Jugadores
* **Gráficos de Radar (Radar Charts):** Comparativa multi-métrica de perfiles estadísticos ajustados por percentiles según demarcación.
* **Gráficos de Dispersión (Scatter Plots):** Matriz de evaluación bidimensional para identificar valores atípicos (*outliers*) y destacar perfiles destacados en la competición.
* **Visualización de Métricas per 90:** Gráficos de barras y perfiles estadísticos individuales para scouting.

---

## 📂 Estructura del Repositorio (Notebooks)

* `WYSCOUT_Graficos.ipynb`: Generación de mapas de eventos, redes de pases y gráficos tácticos sobre campo.
* `WYSCOUT_Graficos_2.ipynb`: Desarrollo de gráficos de dispersión (*scatter plots*) y visualizaciones comparativas.
* `WYSCOUT_Graficos_3.ipynb`: Módulo de diseño de gráficos de radar y perfiles estadísticos avanzados.
